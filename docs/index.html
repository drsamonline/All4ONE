Questions

Frequently asked

Is it really free?

Yes — MIT licensed, free for personal and commercial use. Every line is auditable Python.

Does it need admin rights?

Not for most tools. A few system helpers prompt for elevation the normal Windows way, and destructive tools ask for explicit confirmation.

Will it slow my PC down?

No. It is a portable executable — nothing runs in the background, nothing is installed, nothing starts with Windows.

Why do some tools say “unavailable”?

Heavy tools such as video conversion need optional binaries (FFmpeg, Poppler, Tesseract). Run utility_suite.exe deps and it lists every missing dependency, how many tools it unlocks, and a direct download link.

Can I script it?

Every GUI action has an identical CLI command, so it slots straight into PowerShell, batch files, or scheduled automation.

Is my data sent anywhere?

No. There is no telemetry, no analytics and no network calls except the ones a tool you explicitly run makes.
